# יומן ליווי — אבטיפוס

אפליקציית ווב בעברית (RTL) לתיעוד וליווי פדגוגי של מחנכות במהלך לקידום חינוך מכיל.
גרסה ראשונית עם **נתוני דוגמה פיקטיביים בלבד**.

## הרצה

האפליקציה מחוברת ל-Firebase (פרויקט `yoman-livui`). הכניסה היא עם Google, ולכן צריך לפתוח את האפליקציה דרך כתובת אינטרנט ולא בלחיצה כפולה על הקובץ.

**במחשב:** מריצים בתיקייה `node serve.js` ופותחים את http://localhost:8765

**בטלפון:** אחרי פרסום (GitHub Pages). את כתובת האתר צריך להוסיף ב-Firebase, ב-Authentication → Settings → Authorized domains.

**הרשאות:** רק מי שהמייל שלה מופיע במסמך `config/access` ב-Firestore (שדה `emails`, רשימה של מיילים באותיות קטנות) יכולה להיכנס. את הכללים בקובץ `firestore.rules` מדביקים ב-Firestore → Rules.

## מודל הנתונים

ב-Firestore, תחת `users/<uid>/...`. קבצים נשמרים ב-IndexedDB במכשיר.

- `mentors` — מנחות
- `schools` — בתי ספר (`mentorId`)
- `contacts` — גורמים נוספים (`name`, `role`, `schoolId`); תיעודים איתם מסוג meeting / update עם `contactIds[]`
- `teachers` — מחנכות (`mentorId`, `schoolId`, `className`, `photoFileId`, `intake{}`)
- `records` — **כל סוגי התיעוד במאגר אחד**: `type` (observation / event / personal / group / reflection / goal), `teacherIds[]`, `schoolId`, `status` (draft / final), `data{}`, ובנוסף:
  - `tags[]`, `anchors[]`, `themes[]`, `links[]`
  - בתצפית: `entries[]` (זמן, סוג: נצפה / פרשנות / שאלה, תמה, תגיות), `themeNotes{}`, `talkTimer`
  - ביעד: `progress[]`
  - פגישה משותפת נשמרת **פעם אחת**, ו־`teacherIds` מכיל את כל המשתתפות.
- `files` + `blobs` — הקלטות, תמונות וקבצים (`ownerId` = מזהה התיעוד, `photo:<id>` או `intake:<id>`)
- `settings` — תמות ושאלות מנחות, רשימת תגיות, המנחה הנוכחית

לכל ישות יש `id`, `mentorId`, `createdBy`, `createdAt` ו־`updatedAt`. על השדות האלה יישענו בעתיד הרשאות ושרת.

## מה עובד

- כניסה עם Google. כל מנחה רואה רק את המידע שלה, וגישה ניתנת רק למיילים מאושרים
- שמירה בענן וסנכרון בין מכשירים, כולל עבודה בלי חיבור וסנכרון כשהחיבור חוזר
- מסך בית עם כרטיסי מחנכות, סינון לפי בית ספר וחיפוש לפי שם
- יצירה ועריכה של בתי ספר ומחנכות, כולל צילום או העלאת תמונה
- תיק מחנכת: רצף כרונולוגי עם סינון, רקע ואינטייק, יעדים, גישה מהירה לכל סוגי התיעוד
- אינטייק שנשמר בהדרגה, כולל מערכת שעות כתמונה או כקובץ
- תצפית בשיעור:
  - רשומות עם חותמת זמן והבחנה בין מה שנצפה, פרשנות ושאלה
  - תמות מנחות שנפתחות ונסגרות
  - מדידת זמן דיבור המורה לעומת זמן פעילות הילדים
- תצפית באירוע, פגישה אישית, רשמים ומחשבות
- פגישה משותפת שמופיעה בתיק של כל משתתפת
- יעד עם עדכוני התקדמות וקישור לתיעודים, כולל הצגת קישורים בשני הכיוונים
- בכל תיעוד:
  - הקלטת קול והאזנה, צילום, העלאת תמונות וכמה קבצים
  - שמירה אוטומטית עם חיווי, טיוטות, ומחיקה עם אישור
- מסך "סקירה" (נפתח ראשון): משימות לביצוע שנאספות מ"צעדים להמשך" ו"לבירור" + משימות אישיות; נקודות לזכור (יעדים לבחינה, טיוטות, שאלות מתצפיות, מחנכות שלא תועד איתן מפגש); יום ליווי לפי תאריך; תמונת נתונים של עבודת הליווי
- גורמים נוספים (מנהלת, יועצת, המלווה של ההנהלה, מפקחת…): תיק לכל גורם, פגישות (גם עם כמה גורמים יחד) ועדכונים שהתקבלו
- תמונת מצב של בית הספר: סיכום שמתעדכן לאורך הזמן, בדף בית הספר
- התקנה כאפליקציה (אייקון בטלפון ובמחשב) ופתיחה גם בלי חיבור
- תגיות, תמות ועוגנים, וסינון חוצה תיקים במסך "תיעודים"
- עריכה של תמות, שאלות מנחות ותגיות במסך ההגדרות
- יצוא וייבוא של גיבוי (JSON, כולל קבצים), ואיפוס לנתוני הדוגמה

## מה עוד לא קיים

- **שמירת קבצים בענן** (הקלטות, תמונות, מסמכים). כרגע הם נשמרים רק במכשיר; נדרש מעבר לתוכנית Blaze ושימוש ב-Cloud Storage.
- **גיבוי אוטומטי יומי** של מסד הנתונים (נדרשת תוכנית Blaze).
- תמלול וסיכום של פגישות (מתוכנן; ההקלטה תימחק אחרי אישור התמלול)
- עבודה אופליין מלאה כאפליקציה מותקנת (PWA). הגופן נטען מהרשת, ובלי רשת מוצג גופן חלופי.
- עריכה של מבנה "תצפית באירוע" ושל שדות האינטייק מתוך הממשק (כרגע ב־`js/config.js`)
- מחיקה של תמה (אפשר רק להסתיר אותה, כדי לא לפגוע בתיעודים קיימים)
